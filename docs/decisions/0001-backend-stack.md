# Backend con Python y FastAPI

El backend se construira con Python, FastAPI, Pydantic, Uvicorn y `uv`. Se eligio
Python en lugar de Go porque las siguientes etapas requeriran integraciones con
LLM, agentes, embeddings y RAG, areas donde su ecosistema reduce la complejidad
de experimentacion; a cambio, aceptamos que no estamos optimizando inicialmente
por el menor consumo de recursos o el maximo rendimiento posible.
